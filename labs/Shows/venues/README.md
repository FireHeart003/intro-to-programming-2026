# venues/

A venue is a world this code lives inside: the language, the framework, the database, the
conventions of this team, the rules from outside software. A venue note writes down where
**this** codebase does something a competent stranger would not have guessed.

It is not documentation of everything. It only records the surprises — the places where
"how it works here" differs from "how it usually works." A note you could have guessed is
a note not worth writing.

The files here are a start. You will add to them as you find things.
